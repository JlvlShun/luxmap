# Declaración de uso de IA
Para el desarrollo de la aplicación se utilizó principalmente **Gemini** de Google con la finalidad de obtener información de la documentación y ejemplos prácticos de cada aspecto y herramienta utilizada en la aplicación.

## Ejemplos de consultas
- ¿Cómo funciona map fragment en Android Studio con java para insertar un mapa de Google Maps?
- ¿Cómo funciona RecyclerView para mostrar un listado de datos obtenidos de Firebase?
- ¿Cómo mantener el código desacoplado en un proyecto?
- ¿Cómo funcionan las interfaces de java con callbacks?
- ¿Conviene más serializar un objeto antes de enviarlo a Firebase o lo entrego como tal para almacenarlo?
- ¿Cómo obtener información del sensor de luz del teléfono?
- ¿Cómo administrar y pedir permisos en la aplicación para el uso del gps?

## Otras consultas
- Documentación y ejemplos de uso de Google Maps con marcadores
- Organización de la interfaz con xml para crear layouts en las pantallas
- Aclaración de interfaces usadas como SensorEventListener y OnMapReadyCallback y sus Overrides.
- Instalación del plugin de Secrets Gradle
- Manejo de dependencias en Android Studio
- Reglas de Firebase y administración de cuotas de Google Cloud
- Sintaxis de archivos .md

## Sobre el código de la app
La IA se utilizó para estudio y comprensión del codigo necesario para el funcionamiento de los diferentes aspectos de la aplicación.
El código final fue escrito manualmente a medida que el ejemplo generado sirviese y cumpliese con el objetivo por el que se generó en las consultas.
